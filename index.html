Конвертер кодов "Честный знак" из EPS в CSV

Бесплатно переведет ваши Datamatrix-коды в текстовый вид. Конвертация проходит на вашем компьютере, файлы не утекают на наш сервер.

Отчеты о проблемах присылать на github.



Выберите zip-архив с .eps (или сами файлы .eps). После обработки вы получите список ваших кодов в полном виде с "криптохвостом". Результат — как после сканера: по строке на файл (по порядку имён), разделитель GS (0x1D) сохраняется.
