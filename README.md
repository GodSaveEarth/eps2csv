# Честный знак eps в csv

Набор программ и инструкций для перевода eps из "Честного знака в текстовый файл.


# Введение. В чем проблема?
- Система "Честный знак" позволяет выгружать ваши коды в pdf/eps или сохранять текстом в csv. Но есть проблема: в csv отдают только часть кода, без "криптохвоста". Если такой код распечатать самостоятельно, то при сканировании приложение проверки всегда выдаст "Сомнительный товар".
- Если мы хотим печатать наши коды самостоятельно (например, в bartender), нам надо получить полный код  в текстовом виде с криптохвостом.


# Алгоритм решения 
- Выгрузить коды из ЧЗ в печатном виде eps
- Перевести все коды в bmp 
- Распознать QR код полностью и записать текстом в файл
- Использовать полный код по своем усмотрению 


# Бесплатный веб-конвертер
Работает в тестовом режиме: [https://godsaveearth.github.io/eps2csv/](https://godsaveearth.github.io/eps2csv/).
Принимает zip-архив c esp-кодами и конвертит в текстовый вид используя облако Яндекса. Работает пока работает.


# Набор программ под Windows

## Нужные программы
```
ImageMagick - ImageMagick-7.1.2-33-Q8-x86-dll.exe
Ghostscript - gs10080w32.exe
dmtxread.exe и gawk.exe - выложены в этом репо
```

## Порядок действий
1. распаковать все eps в каталог
2. перевести все eps в bmp
```sh
for %i in (*.eps) do gswin32c -q -dNOPAUSE -dBATCH -dEPSCrop -sDEVICE=bmpmono -r300 -sOutputFile="%~ni.bmp" "%i"
```
3. распознать каждый bmp файл в текст
```sh
for %i in (*.bmp) do dmtxread -n "%i" >>out.txt
```
4. на всякий случай очистить дубликаты в текстовом файле
```sh
gawk.exe "!seen[$0]++" out.txt > clean.txt
```


# Набор программ под Linux

## Нужные программы
```
sudo apt update
sudo apt install dmtx-utils
sudo apt install ghostscript
```

## Порядок действий
1. распаковать все eps в каталог
2. перевести все eps в bmp
```sh
gs -dSAFER -dBATCH -dNOPAUSE -sDEVICE=bmpmono -r300 -dEPSCrop -sOutputFile=out%d.bmp *.eps;
```
3. распознать каждый bmp файл в текст
```sh
for filename in *.bmp; do	
    dmtxread -n $filename >> out.txt;
done
```
4. на всякий случай очистить дубликаты в текстовом файле
```sh
awk -i inplace '!seen[$0]++' out.txt
```
